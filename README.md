# zunh22 — Security Research Notes

GitHub Pages portfolio for malware analysis, CVE labs, wargame writeups, and CTF recaps.

Site: https://zunh22.github.io/security-research-notes/

## Structure

- `posts/malware/` — malware analysis
- `posts/cve/` — CVE analysis and safe lab practice
- `posts/wargame/` — wargame writeups
- `posts/ctf/` — CTF writeups and recaps

Each board has its own page. The theme toggle supports light and dark mode and remembers the visitor’s choice.
